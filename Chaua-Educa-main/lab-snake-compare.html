Os tempos CPU medem o envio dos desenhos ao Canvas, excluindo tronco e guias. O intervalo entre quadros pertence à página inteira, com as duas versões abertas. Esses números não medem VRAM, tempo de GPU ou FPS do jogo no seu aparelho. Para medir cada versão isoladamente, selecione “Somente oficial” ou “Somente articulada”, mantenha os mesmos controles e aguarde as amostras. Baixe um JSON de cada execução para comparar no mesmo aparelho. A boca tem duas expressões; a abertura de mandíbula ainda precisa de uma peça própria para uma transição contínua.
